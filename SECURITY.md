# Política de seguridad

## Comunicar una vulnerabilidad

No abras un issue público. Usa **GitHub → Security → Report a vulnerability** (aviso privado) en
este repositorio. Responderemos lo antes posible y te mantendremos informado hasta su corrección.

## Alcance

La aplicación web, sus migraciones de base de datos y su configuración de despliegue. El detalle de
controles y del modelo de amenazas está en [docs/seguridad.md](docs/seguridad.md).
